This template implements the BSC/MSC thesis in format of conference or journal paper. For some examples, please see the "examples" folder.

Also, your corrections and improvements to this thesis template are highly appreciated. If you would like to contribute, open a pull request. After the review we may merge the appropriate changes into the repository.
